- Check-in procedure: a hub operation's `memory/` check-in by the base's `scripts/hub.py write … --root <hub>`, which writes and checks in only the paths it edits under `memory/`, as one changeset, never through the `vc-checkin` agent; every other check-in by the `vc-checkin` agent of this pack, which runs the ceremony and returns the changeset number; `cm` ceremony is never run on the main thread outside the base's `scripts/hub.py`
- Base-revision reads: `cm cat "<repo-relative-path>#cs:N"`; `cm diff cs:A cs:B --format="{status}|{path}{newline}"`; `cm merge "br:<source>" --machinereadable` (`<source>` is the source branch's full name, leading slash included, as `cm wi` reads it in a workspace on that branch), run in the destination's workspace, for the log read and the changed-file read from the merge base — it changes nothing and lists what `<source>` holds that the destination lacks, one line per item with its path, and `STATUS ALREADY_CONNECTED` alone is none; `cm status`; `cm wi` for the current branch — its output names the workspace's repository and its branch or label, so the branch is read out of that line, and a workspace switched to a label reports none; never `cm diff` on file content — it launches a GUI difftool and hangs headless; TODO (the per-file line-count read — each changed file's added and deleted lines between two changesets; no `cm` read for it is known)
- Merge procedure: on the main thread behind the gate's human ruling, with a clean workspace first (`cm merge` refuses with any pending change) — where the `trees` binding is filled, the merge runs in the hub, on the main branch, and nothing is switched; otherwise `cm switch <destination-branch>` first where the workspace is on another branch — then the preview `cm merge "br:<source-branch>" --machinereadable` (`<source-branch>` is the source branch's full name, leading slash included, as `cm wi` reads it in a workspace on that branch), where a line not beginning `STATUS`, `FILE_SRC` or `APPLY` is a conflict for the human, then `cm merge "br:<source-branch>" --merge`; the runbook is `.claude/references/vc-plastic/merge-ceremony.md`.
