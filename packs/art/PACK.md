# art

A deliberate placeholder: the art axis has a name on the roster and nothing behind it. Filling it means inheriting the pattern every craft pack carries — a document template for the art spec the craft produces, an orchestration skill that authors that document, one review angle that states the craft's quality bar, a preflight check the gate audit runs against a finished spec, a binding key on the `<craft>-<artifact>` convention that says where the specs live, and a spec author to write them. Until a feature does that work the pack provides nothing, requires nothing and declares no trigger, so no composer proposes it and no project can usefully compose it; it exists to make the axis legible and to name what the filling feature owes.
